First-run setup

Setup has already been completed. Configuration lives in .env. To change it, edit that file directly and restart with docker compose up -d. Go to the dashboard.

Let's get you connected

This system reads arXiv for you every day, indexes the newest papers into a local vector store, and lets anyone chat with a Telegram bot to ask questions about them — grounded in the actual paper text, with citations. Every subscriber gets a morning digest of what's new.

The embeddings and the language model run locally through Ollama. No paper content or user question ever leaves this machine. Your Telegram bot token is written to a local .env file and never sent to your browser again after saving.

1

Choose your n8n login

You'll use this to sign in to the workflow engine at localhost:5678. Make it up now — the account is created for you automatically.

2

Telegram — where users chat with the bot

Open Telegram, message @BotFather, and send /newbot. Follow the prompts to name your bot and choose a username ending in bot. BotFather replies with a token that looks like 123456789:AAH... — that's what goes below.

3

Public URL — how Telegram reaches your bot

Telegram delivers messages by calling a public URL, so localhost needs a tunnel in front of it. The easiest free option that needs no account is cloudflared: 

cloudflared tunnel --url http://localhost:5678

It prints a URL like https://random-words.trycloudflare.com. Paste it below (with a trailing slash). If you're deploying to a VPS or n8n Cloud with a real domain, use that URL instead and skip the tunnel entirely.

4

arXiv categories — what to read

A comma-separated list of arXiv category codes to monitor. Popular ones for ML/AI: cs.AI, cs.LG, cs.CL, cs.CV, stat.ML. The full taxonomy is here. You can change this any time from the dashboard.

Configuration saved

Your keys were written to .env. One last step to bring everything online:

docker compose up -d

Run that in the Research-Intelligence folder. If you started this with start.ps1 or start.sh, it is already happening automatically — just wait a moment. Setup then creates your account, provisions the vector store, pulls the Ollama models, and switches both workflows on.

First-run models are big: llama3.2 is roughly 2 GB and nomic-embed-text is around 275 MB. Both download once and are cached.
